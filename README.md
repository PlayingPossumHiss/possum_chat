# Хотелось бы иметь мультичат под линукс

## Запуск приложения

При запуске имеем окно с тремя вкладкам

![Соединения](./docs/connections.png)

Первая - окно соединений. Мы можем указать для каждого из источников ключ, а именно:
- Для ютуба имя канала (без @) или ключ трансляции (из адресной строки)
- Для VK Play Live, Kick или Twitch - имя канала (без @)
- Для Donation Alerts - ~~токен из адресной строки виджета для OBS~~ Пока не работает, поменялся контракт

Для каждого из соединений имеется кнопка для запуска вычитки сообщений

Так же внизу есть ссылки на виджет OBS, страницу для просмотра всех сообщений и ссылка на этот репозиторий

Обращаю внимание, что для OBS есть две отдельные страницы: с чатом и с виджетом на весь экран:
- Чат выводит собственно весь чат и онлайн
- Полноэкранный работает с командами (см. [Команды чата](#Команды_чата))

![Стили](./docs/css.png)

Вторая вкладка позволяет настроить кастомные стили в виджете

Так же есть выбор из основных стилей (пока что их только два) и отправка тестового сообщения

Имейте ввиду, что вкладку браузера приизменении стиля надо будет обновить

![Настройки](./docs/settings.png)

Настроки, а именно:
- Время через которое сообщение пропадет в виджете (т.е. у зрителей)
- Время через которое сообщение будет удалено изпамяти (т.е. в формета просмотра для стримера см. "удобно для просмотра на втором экране" в разделе Виджет)
- Порт на котором будет запушен виджет. Требует перезапуск
- Язык (английский или русский). Требует перезапуск
- Версия
- Текущая версия на Github, а так же возможность обновить ее по нажатию кнопки (отображается, если текущая версия отличается от актуальной)

## Виджет

http://127.0.0.1:8081/messages.html - виджет для OBS будет тут после запуска
http://127.0.0.1:8081/messages.html?for_last=1h - если хотим отображать все комментарии за последний час
http://127.0.0.1:8081/messages.html?for_last=1h&use_scroll=true - если в дополнение к этому хотим, чтобы список можно было скролить (удобно для просмотра на втором экране). Так же можно увидеть ошибки, если они были в логах
http://127.0.0.1:8081/widget.html - полноэкранный виджет для вывода того, что надо показывать исходя из всего расмера экрана

## Команды чата

Есть поддержка команд в чате:
- Если вы введете в любом подключеннном чате `--vote one;two;tree`, то будет запущено голосование с этими вариантами. После этого варианты будут отображены наверху экрана, а если пользователи будут писать номер своего варианта, то голос будет засчитыаться. Закончить голосование можно командой `--vote` без параметров
- Если вы введете в любом подключеннном чате `--message some text`, то этот текст будет выведен в нижнем правом углу виджета. Сбросить его можно командой `--message` без параметров

## Конфиг

При запуске в папке с приложением должен лежать файл config.json следующего вида. Сейчас почти все параметры вынесены в настройки, но иногда может быть нужно указать уровень логирования и путь (для расследования багов)

``` json
{
	"connections": {
		"youtube": {
			"channel_name": "PlayingPossumHiss" // так же это может быть идентификатор трансляции
		},
		"twitch": {
			"channel_name": "playingpossumhiss"
		},
		"vk_play_live": {
			"channel_name": "playingpossum"
		},
		"donation_alerts": {
			"token": "I'm a token"
		}
	},
	"loging": {
		"log_path": "./log.log",
		"level": "INFO"
	},
	"view": {
		"css_style": "",
		"time_to_hide_message": "2m0s",
		"time_to_delete_message": "1h0m0s"
	},
	"port": 8081,
	"version": "1.0"
}
```
